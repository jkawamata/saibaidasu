# 栽培ダス

気象庁のアメダス観測データを、地図・グラフ・表・栽培期間の積算指標で確認するWebアプリです。

## 公開ページ

GitHub Pages: https://jkawamata.github.io/saibaidasu/

## バージョン

- 最新版: V1.02
- 公開入口: `index.html`
- 版保存ファイル: `saibaidas_v1.02.html`

## 主な機能

- 地図から全国のアメダス観測地点を選択
- 一週間・一か月・年度・指定期間のグラフと表
- 2地点および過去年の横並び比較
- 栽培期間の有効積算温度、積算降水量、推定日射量、低温遭遇時間
- 3日以内の連続欠損を前後の観測値から補完し、補完日数を表示

表示にはインターネット接続が必要です。このアプリは気象庁の公式アプリではありません。
