# 栽培ダス

気象庁のアメダス観測データを、栽培に役立てやすい地図・カード・グラフ・表・気象指標として表示する単一HTMLのWebアプリです。

## 公開ページ

[栽培ダスを開く](https://jkawamata.github.io/saibaidasu/)

インターネット接続が必要です。PCのほか、iPadなどのタブレットでも利用できます。

## 現在のバージョン

- 最新版：V1.36
- 公開入口：`index.html`
- 版保存ファイル：`saibaidas_v1.36.html`

`index.html`と版保存ファイルは同じ内容です。ローカルで使う場合はHTMLファイルをダウンロードし、ブラウザで直接開いてください。機能を変更したときは、ファイル名と画面内のバージョンを0.01ずつ上げます。

## 主な機能

### アメダス観測データ

- 初回は東京を表示し、日本地図・地点一覧・検索から全国の観測地点へ変更
- 地図の拡大時に観測地点名を表示し、タッチ操作やダブルクリックでも地点を確定
- 気温、降水量、風速、湿度、日照時間、積雪深の最新値と推移を一覧表示
- 一日、一週間、一か月、年度、任意期間を切り替えて表示
- 一週間は日曜日から土曜日、一か月は1日から月末、年度は4月から翌年3月までの固定範囲を確保
- 観測データがない日時は、グラフ上の場所だけを確保して空白表示
- 各項目の詳細グラフと観測表を全画面表示し、CSVとして保存
- 同じ期間の2地点比較、または同じ地点の1年前から10年前までの比較
- 「今日として扱う日」を変更し、その日を基準に全画面と栽培気象分析を再表示
- 過去日を今日として表示した場合、その日より後に実在する観測値を計算対象外の参考データとして薄く表示
- A4縦位置に収まるよう調整した印刷表示

### 栽培気象分析

- 栽培開始日と終了日を月日で指定し、対象年度へ自動的に対応
- 有効積算温度の基準温度と、低温判定温度をプルダウンで指定
- 月日や温度条件を変更すると、ボタン操作なしで自動再計算
- 通常表示、過去年との比較、2地点比較を切り替え
- 次の気象指標を表示
  - 栽培期間と経過日数
  - 積算気温、有効積算温度（GDD）
  - 平均気温、最高気温、最低気温
  - 積算降水量、降水日数
  - 積算日照時間、推定積算日射量
  - 猛暑日、真夏日、夏日、日最低25℃以上の日、低温日、冬日
  - 推定低温遭遇時間
- 印刷時にも栽培開始日、終了日、基準温度、低温判定を表示
- 作物名から、温度・水分・日照などのテーマ別Google検索を新しいタブで開く

## 欠損データの扱い

栽培気象分析では線形補間を使用しません。観測値が欠損している日・項目ごとに、元の観測地点から距離の近い別のアメダス観測地点を順番に確認し、同日の実測値で補完します。

- 距離の近い候補を最大12地点まで確認
- 降水量の欠損には、降水量のみを観測する地点も補完元として利用
- 補完に使った地点名・距離・対象日数を画面に表示
- 近隣地点にも値がない項目は補完せず、その項目の計算対象から除外
- 欠損がない場合も「データ欠損はありません」と表示

## 計算方法

- 積算気温・有効積算温度・平均気温：日平均気温から計算
- 最高・最低気温と気温別日数：日最高・最低気温から計算
- 積算降水量・降水日数：日降水量から計算（降水日は1mm以上）
- 猛暑日：日最高35℃以上
- 真夏日：日最高30℃以上
- 夏日：日最高25℃以上
- 冬日：日最低0℃未満
- 積算日射量：日照時間と緯度から推定
- 低温遭遇時間：日最高・最低気温から推定

基準温度と低温判定温度は作物や栽培方法によって異なります。信頼できる栽培資料を確認して設定してください。推定値や隣接地点による補完値は、栽培判断を補助する参考情報として利用してください。

## データと外部サービス

- 観測データ・観測地点：気象庁「アメダス」「過去の気象データ検索」
- 地図：国土地理院の白地図
- グラフ：Chart.js
- 地図表示：Leaflet
- 作物の関連情報：Google検索

観測値には速報値が含まれ、後から修正される場合があります。地点によって観測していない気象項目もあります。このアプリは気象庁の公式アプリではありません。
